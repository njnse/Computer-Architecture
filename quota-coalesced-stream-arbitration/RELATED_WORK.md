# Verified sources and mechanism relationship

* Matt Weber, **Arbiters: Design Ideas and Coding Styles**, SNUG Boston. [Primary paper](https://abdullahyildiz.github.io/files/Arbiters-Design_Ideas_and_Coding_Styles.pdf). The paper was opened and its title, author, and request/grant/round-robin discussion inspected. It motivates interface correctness and alternative coding structures, including masked priority approaches. This artifact uses an independently written masked round-robin baseline; it does not reproduce the paper's synthesis numbers or claim an identical implementation.
* Charles Eric LaForest, **A Round-Robin Arbiter**, FPGA Design Elements. [Author's implementation description](https://fpgacpu.ca/fpga/Arbiter_Round_Robin.html). The description and source were inspected. It explains masked cyclic selection and retaining arbitration history across idle intervals. Its grant is held until request release; this artifact instead arbitrates independent ready/valid beats, advancing only on actual transfers and adding a bounded accepted-beat quota. No source code from that implementation is redistributed.
* Icarus Verilog project, [language extensions documentation](https://steveicarus.github.io/iverilog/usage/icarus_verilog_extensions.html). This documentation was accessible. The actual capability relied on here is established by compiling and executing the checked-in harness, rather than inferring full SystemVerilog/UVM support from a project name.

The Yosys `synth_ice40` online documentation endpoint could not be opened by the browsing tool. Mapping evidence instead comes from the executed pinned tool, full logs, generated netlists, and machine-readable cell types. No unsupported documentation claim is substituted for those outputs.

These sources establish relevant prior mechanisms; this is not a systematic literature review. Grouped/quota scheduling is an established idea. The experimentally grounded contribution here is the particular handshake-safe RTL artifact, bounded service-opportunity checks, independent fault-sensitive measurement path, and mapped resource/fairness comparison. A novel scheduling policy or publication-level claim would require a broader primary-literature search and substantial application/timing evidence.
