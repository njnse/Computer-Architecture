# Toolchain, workload and reproduction

```bash
python3 run_project.py
```

The complete command verifies runtime pins, trains all six models, executes independent tests and RTL/public replays, synthesizes 45 designs, replays generic netlists, runs bounded formal, generates figures/reports, audits results and packages logs. It overwrites generated `results/` and writes `build/`. A fresh full run is the independent reproduction path. `--resume-synthesis` continues only after a completed simulation stage.

## Runtime

Linux x86-64, Python 3.12.14, `venv`, `dpkg-deb`. Native Windows is not supported by the pinned Debian package; use a compatible Linux environment/WSL. Bootstrap installs locally without root and requires initial HTTPS access. Main packages are fully pinned in `requirements.txt`: NumPy 2.3.5, SciPy 1.17.0, scikit-learn 1.8.0, Matplotlib 3.10.8. BLAS/OpenMP/MKL thread limits are fixed to one before NumPy initialization for small deterministic CPU training.

Icarus 12.0 comes from Debian `12.0-2+b1`, SHA256 `febe027d2d3f5a7e570844d55758339ab5490acc09f404f214a8719d89d07056`. YoWASP Yosys package `0.69.0.0.post1233` uses Yosys revision `9f75ca1f9`; runtime dependencies are pinned in `tools/requirements.txt`. Validated execution reused matching provisioned tools with `IVERILOG`, `IVL_BASE`, `VVP`, and `YOSYS` selectors. `preflight.py` checks actual installed packages and the Icarus package hash. A fresh network bootstrap was not rerun on this already provisioned worker.

Writable `XDG_CACHE_HOME`/`MPLCONFIGDIR` avoid the read-only worker home. The environment/commands/source hashes are retained without secrets. Reproduction needs no GPU, remote login or board.

## Workload provenance

E. Alpaydin and C. Kaynak's UCI *Optical Recognition of Handwritten Digits*, [DOI 10.24432/C50P49](https://doi.org/10.24432/C50P49), is loaded by pinned scikit-learn. The [primary dataset page](https://archive.ics.uci.edu/dataset/80/optical+recognition+of+handwritten+digits) states CC BY 4.0. That attribution also applies to transformed measurements. Pixel/label hashes and exact split indices are in `fixtures/provenance.json`. The 1,797-image original test subset is re-split into 1,077 training, 360 validation and 360 test images; this is not the official writer-independent benchmark.

`train_models.py` newly trains six 64→32→10 MLPs with Tanh/ReLU and seeds 7/31/97, 120 Adam epochs each. Minimum validation cross entropy selects the checkpoint; ReLU hidden range is calibrated from validation only, while Tanh uses its mathematical bound. All training history, checkpoints and configuration are retained. Test labels never tune the recoder, model selection or calibration.

Hidden activations are generated by the host's floating first layer/activation. Only the quantized output-layer block dot products execute in RTL. The host also reduces blocks, rescales and applies bias/argmax. This does not implement complete fixed-point inference.

`results/experiment_config.json` distinguishes workload-generation, model-training and SV readiness-driver seeds. In particular, `seed` in simulation rows refers to the driver; named synthetic streams separately encode their generation seed. An assigned negative sign leaves zero unchanged, so sign-selection probability is not the exact observed negative-value fraction.

The activation profile field `hidden_clipped_fraction` counts `abs(hidden) > calibration_bound` before integer rounding. The report labels it hidden-bound exceedance; it is not a count of integer values changed by the final clip operation. Actual quantization uses the exact documented round-and-clip expression.

The retained training-determinism record describes the validated worker's cross-check, not an additional independent sample or a guarantee across CPU/BLAS implementations. A full reproduction trains each checkpoint once; bitwise floating-point training on different hardware is not promised. For frozen-checkpoint replay, `python3 reproduce.py reuse-models` uses retained models/history after tool selectors and runtime are prepared.

## Implementation limits and licensing

Generic synthesis and `synth_xilinx -family xcup -flatten -noiopad` execute on the tested RTL. DSP-disabled cases add `-nodsp`; one parallel mapping allows DSP inference. `xcup` is an actual logical UltraScale+ family mapping, not an exact K26 device/board implementation. Full cell types and logical LUT/FF/DSP counts come from emitted netlists. Generic counts are not LUT counts or physical area.

YoWASP synthesis stdout can stop around ABC/ABC9 while emitting complete netlists. Logs are retained as received; every netlist is independently reloaded, checked and printed cell counts verified. Do not call partial stdout a complete synthesis transcript. Compact archived top designs omit redundant unused cell-library modules; pinned library declarations are supplied on readback. Original and retained-design hashes are distinct.

No Vivado, executed UVM runtime, place-and-route target, private HiPerGator connection or KV260 execution was available here. Reported cycles do not imply MHz/ns/Fmax, physical throughput, power or energy. No such estimates are fabricated.

Icarus is GPL-licensed; Yosys is ISC-licensed. Binaries/tool sources are not redistributed by this artifact; bootstrap obtains them upstream. Compressed `.log.gz.b64` files decode with Python base64 then gzip. `MANIFEST.json` hashes uploaded content; the one-command run regenerates per-run raw CSVs in `build/`.
