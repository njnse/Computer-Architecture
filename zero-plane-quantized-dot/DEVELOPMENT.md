# Development and exploratory revisions

The shared bitmap mechanism and protocol were specified before implementation. The initial arithmetic tests and synthetic RTL comparisons passed, then public density analysis exposed an API type mismatch: NumPy integers do not have Python `bit_length`. The run stopped before application measurement and synthesis; `results/exploratory_failure.log` records it. The mathematical reference now converts values to Python integers.

Primary full-text inspection of Dynamic Stripes identified both leading and trailing offset trimming. A leading-only comparison would understate that prior mechanism. Before completing the experiment, the in-progress run was stopped and a fifth executed baseline was added: contiguous span from lowest to highest active plane. The original leading-only mode is retained as an ablation. No held-out label was used for this revision. Initial guessed literature identifiers resolved to unrelated papers and were rejected; only verified identifiers are cited.

No training, accuracy-driven parameter tuning, or outcome-dependent workload filtering is performed. The final widths, lane groups and traffic are fixed. A successful write-access preflight stored the initial specification as a detached Git blob; it did not publish a branch or constitute a completed project upload.

The first completed public replay reached the mutation gate, where the stalled-output overwrite mutation escaped a short random-ready test. This was a verification-stimulus gap: random stalls were too short to force overwrite before consumption. The run was rejected and its traceback retained in `results/exploratory_mutation_failure.log`. The mutation test now forces periodic ready (one in eight cycles). An independent diagnostic run then detected changed stalled output at cycle 5. Final evidence is regenerated with this stronger gate. Raw command output and incremental measurements are now persisted during execution so interruption cannot discard completed measurements. This is not a discovered defect in the final unmutated RTL.

The bounded formal flow initially rejected edge-triggered `$check` cells. The tool-specific preparation now applies `async2sync`, `chformal -lower` and `dffunmap` before SAT. All five completed final proofs retain scripts and logs; the earlier preparation errors are not proof counterexamples.

A second implementation of the contiguous-span rule was added as mode 5 before final area conclusions: it stores low/high bit offsets and advances a small counter, without the shared bitmap priority selector. It is executed as a stronger prior-mechanism baseline, while mode 4 remains the matched-template ablation. The additional comparisons reuse the frozen workload/seed/traffic grid and do not tune to test labels. This prevents attributing avoidable bitmap-control overhead to Dynamic Stripes's counter-based prior mechanism.

The first generic netlist was synthesized, then Icarus rejected RTL parameter overrides because the netlist top is already specialized and has no parameters. The diagnostic is retained in `results/exploratory_netlist_compile_failure.log`. Netlist compilation now defines `NETLIST` so the testbench instantiates the specialized top without overrides; the testbench's widths still match that measured configuration. Unchanged completed RTL measurements are retained and synthesis/gate verification resumes through the runner's `--resume` mode. Fresh reproduction uses the default full runner.

Mapped-cell inspection found reset-only serial-control state retained in the initial parallel-mode Xilinx netlist, despite having no reachable role after reset. Reporting that cost as an optimized multiplier baseline would be unfair. The serial update branch is now statically excluded in parallel mode. Only parallel-mode measurements and its five mappings are replaced after executing the full same workload grid again; unchanged other modes remain valid. The original source hash and mapping evidence are retained as exploratory diagnostics, not final comparison data. Reset-active coverage is now derived from outstanding transactions/output status rather than a DUT-internal state name, allowing a fully specialized netlist to be checked as a black box.

The final audit found that captured YoWASP synthesis stdout stops at the ABC/ABC9 invocation, although each tool command returns zero and emits the requested complete JSON/Verilog netlists. No complete synthesis transcript is claimed. The actual partial stdout is preserved. An additional independent readback reloads all thirty emitted JSON netlists, restores FPGA primitive library parameter declarations, executes structural `check -assert` and prints `stat`; those printed cell-type counts are cross-checked against the archived JSON resource summaries. Full independent readback evidence is retained. The audit therefore relies on emitted products and executed readback/gate checks instead of a missing end-of-log marker.
