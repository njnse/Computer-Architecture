# Verified related work and contribution boundary

[Bit-Pragmatic Deep Neural Network Computing](https://arxiv.org/html/1610.06920v1), by Albericio, Judd, Delmas, Sharify and Moshovos, establishes essential-bit execution and discusses neuron-lane synchronization. Sections V and VI were inspected. The present implementation uses one shared union bitmap per small dot group; it does not reproduce Pragmatic's independent neuron offsets, memory tiles or complete convolution accelerator. Skipping zero bits is established prior art.

[Dynamic Stripes](https://arxiv.org/html/1706.00504v1), by Delmas, Judd, Sharify and Moshovos, detects both ends of the active bit range of an activation group. Sections II and III were inspected. Our mode 4 preserves all planes between those endpoints and is the applicable prior-mechanism baseline. Mode 2 only trims the top and is an ablation. Modes 1–4 share a bitmap scheduler template for an implementation ablation. Mode 5 implements the contiguous-span rule with small offset registers and a counter, supplying a stronger prior-mechanism baseline. Neither reconstructs the full Dynamic Stripes accelerator. Published system-level speedups cannot be compared directly with these endpoint cycles.

[Integer-only quantization](https://arxiv.org/abs/1712.05877), by Jacob and colleagues, motivates exact integer operators. Its primary abstract was verified. This artifact only executes quantized block dots in hardware; class accumulation and floating scaling/bias are explicitly host postprocessing, and no new QAT method is proposed.

[UCI optical digits](https://archive.ics.uci.edu/dataset/80/optical+recognition+of+handwritten+digits), DOI 10.24432/C50P49, is attributed to Alpaydin and Kaynak under CC BY 4.0. The checkpoint and split provenance are copied byte-for-byte from the previous project. The sklearn 1,797-image subset is not the original complete writer-independent benchmark. Only the checkpoint is redistributed; the installed sklearn loader supplies data.

The contribution is executable signed RTL and verification evidence, a strong contiguous-span scheduling comparison, grouping and input-distribution boundaries, and mapped resource costs. This is a completed bounded experimental artifact, not an established novel research algorithm or a thesis/NeurIPS/architecture-conference-ready paper. An exhaustive recent-literature search has not been performed.
