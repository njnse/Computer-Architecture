# Toolchain and execution scope

The scientific runtime is Python 3.12 with all Python package versions pinned in `requirements.txt`. The simulation tool is Icarus Verilog 12.0, Debian `iverilog_12.0-2+b1_amd64.deb`, verified SHA-256 `febe027d2d3f5a7e570844d55758339ab5490acc09f404f214a8719d89d07056`. It is GPL licensed; installer fetches the package instead of redistributing tool binaries. Synthesis is YoWASP Yosys 0.69, revision `9f75ca1f9`, with exact distribution/runtime pins in `tools/requirements.txt`. Source setup scripts are reused from the preceding artifact; they install locally, without a privileged package install. Internet is required only for initial dependencies; experiments use installed sklearn data.

`python3 run_project.py` is the one-command reproduction entry point on Linux x86-64 with Python 3.12, glibc compatible with the Debian package, `venv`, and `dpkg-deb`. It bootstraps local tools if missing, selects pinned scientific packages, then executes simulation, synthesis, reduced bounded formal checks, DSP-enabled mapping, analysis and audit. Tool binaries, caches and build intermediates are excluded from Git. All seeds and command arguments are retained. Set `XDG_CACHE_HOME` to a writable directory if supplied externally. Runtime details are recorded in `results/environment.json`.

An already installed toolchain can be selected through `IVERILOG`, `IVL_BASE`, `VVP` and `YOSYS`. The measured environment used `/workspace/rtl-tools/iverilog/usr/bin/iverilog`, `/workspace/rtl-tools/iverilog/usr/lib/x86_64-linux-gnu/ivl`, `/workspace/rtl-tools/iverilog/usr/bin/vvp` and `/workspace/rtl-tools/venv/bin/yowasp-yosys`, with `XDG_CACHE_HOME=/workspace/rtl-tools/cache`. Commands use these external paths in the recorded evidence; they are not requirements for a fresh checkout.

No UVM-compatible simulator/library was installed or executed. The actual environment is a plain SystemVerilog driver, independent transaction scoreboard, protocol assertions and coverage counters, driven by deterministic Python workloads. It must not be called UVM. No Vivado installation/license, routed clock constraint, KV260 connection, board measurement, GPU or HiPerGator SSH identity is available here. Generic cell counts and logical `xcup` mapping do not establish FPGA frequency, native K26 placed resources, timing closure or power.

The default command is a fresh full experiment. `python3 run_project.py --resume` retains previously completed unchanged RTL measurements and reruns synthesis, gate verification and later stages; use it only when `results/simulation.json` and other completed simulation evidence exist. The final run used this recovery after the documented specialized-netlist elaboration error. Compressed `.gz.b64` evidence can be decoded with Python `gzip.decompress(base64.b64decode(path.read_text()))`. VCD wall-clock header metadata is removed during packaging; signal transitions are preserved.

The retained netlist archive contains the complete flattened `dot_engine` module for every configuration, including cell connections, parameters and net attributes. Redundant copies of unused Yosys primitive library modules are omitted. Exact pinned `cells_sim.v` and `cells_xtra.v` declarations are reloaded for mapped-netlist structural/statistics checks. `retained_design_sha256` hashes canonical retained design JSON; `netlist_sha256` records the original full tool-emitted build JSON. Cell totals include debug `$scopeinfo` metadata where present; all types remain visible, while LUT/FF/DSP metrics count only matching physical primitive types.
