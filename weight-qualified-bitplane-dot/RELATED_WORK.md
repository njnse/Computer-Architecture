# Verified primary literature and scope

- Jorge Albericio, Patrick Judd, Alberto Delmas, Sayeh Sharify, and Andreas Moshovos, *Bit-Pragmatic Deep Neural Network Computing*, [arXiv:1610.06920](https://arxiv.org/abs/1610.06920). The primary [full text](https://arxiv.org/html/1610.06920v1) describes bit-serial activation/bit-parallel weight arithmetic that processes essential activation bits. Our bitmap scheduler shares the bit-skipping idea, but has a single shared group mask and an explicitly signed two's-complement datapath. It does not reproduce Pragmatic's full lane synchronization, memory system, or accelerator.
- Alberto Delmas, Patrick Judd, Sayeh Sharify, and Andreas Moshovos, *Dynamic Stripes: Exploiting the Dynamic Precision Requirements of Activation Values in Neural Networks*, [arXiv:1706.00504](https://arxiv.org/abs/1706.00504). The primary [full text](https://arxiv.org/html/1706.00504v1), Sections II and III, describes group OR signals, leading/trailing one detection, and counter-based contiguous processing. Our separate counter RTL implements this scheduling rule at the matched block endpoint. It is a mechanism baseline, not a reproduction of the complete Dynamic Stripes architecture.
- Alberto Delmas Lascorz, Patrick Judd, Dylan Malone Stuart, Zissis Poulos, Mostafa Mahmoud, Sayeh Sharify, Milos Nikolic, and Andreas Moshovos, *Bit-Tactical: Exploiting Ineffectual Computations in Convolutional Neural Networks: Which, Why, and How*, [arXiv:1803.03688](https://arxiv.org/abs/1803.03688). The primary [full text](https://arxiv.org/html/1803.03688v1), Sections 4 and 5, combines statically scheduled weight sparsity with effectual activation bits or dynamic precision. This directly prevents any claim that combining zero weights and bit sparsity is new. Our qualification is an on-handshake group-union filter with no lookahead/lookaside weight compaction, changed input format, or static weight schedule.

These primary texts were inspected. The literature coverage is selective, not an exhaustive novelty review. This completed artifact measures a bounded implementation/control tradeoff; it does not claim a new sparsity algorithm or a conference-ready architecture.
